# Python Inheritance & OOP

A collection of Python programs created to practice Object-Oriented Programming (OOP) concepts, with a focus on inheritance and class relationships.

## Topics Covered

- Classes and Objects
- Base Classes
- Inheritance
- Single Inheritance
- Multiple Inheritance
- Multilevel Inheritance
- Encapsulation
- Object-Oriented Programming (OOP)

## Programs Included

- `Basedclass.py` – Basic class and base class concepts
- `inheritance.py` – Python inheritance example
- `Multipleinheritance.py` – Multiple inheritance implementation
- `MultilevelInheritance.py` – Multilevel inheritance implementation
- `encapsulation1.py` – Encapsulation concepts
- `OOPs.py` – Basic object-oriented programming concepts

## Technologies Used

- Python 3
- Object-Oriented Programming

## Purpose

This repository contains practice programs developed while learning Python OOP. It demonstrates how classes can be structured and reused through inheritance, along with related concepts such as encapsulation.
